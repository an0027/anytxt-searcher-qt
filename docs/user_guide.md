## 1. 概述

AnyTXT Searcher 是一款高性能桌面全文搜索工具，支持中文分词和多种文档格式。无需等待漫长的索引过程，即可快速从海量文档中找到所需内容。

**核心特性：**

- **全文搜索**：对文档内容进行全面索引和搜索
- **中文分词**：内置中文分词支持，准确搜索中文内容
- **多格式支持**：支持 TXT、PDF、DOCX/DOC、XLSX、PPTX、EPUB、EML、RTF、WPS 系列等
- **实时监控**：自动监控文件夹变化，保持索引最新
- **即时预览**：搜索结果预览 + 命中段落定位
- **智能筛选**：按文件类型、修改时间、文件大小筛选
- **主题系统**：亮色/暗色主题切换
- **分页导航**：大量结果时支持翻页

## 2. 安装

### 系统要求

- **操作系统**：Windows 7+ / Linux / macOS
- **运行时**：Qt 6.x (推荐) 或 Qt 5.15+
- **搜索库**：Xapian 1.4+

### 安装步骤

#### Windows

1. 从发布页面下载安装程序（.msi 或 .exe）
2. 运行安装程序，按照指引完成安装
3. 启动程序，首次运行会自动创建索引

#### Linux

```bash
# 编译安装
git clone <repository-url>
cd anytxt-searcher-qt
mkdir build && cd build
cmake ..
make -j$(nproc)
sudo make install
```

#### macOS

```bash
# 使用 Homebrew 安装依赖
brew install qt xapian poppler libzip tesseract leptonica

# 编译安装
git clone <repository-url>
cd anytxt-searcher-qt
mkdir build && cd build
cmake ..
make -j$(sysctl -n hw.ncpu)
```

### 可选依赖

某些格式需要额外安装系统库：

| 依赖 | 功能 | 安装方式 (vcpkg/包管理器) |
|------|------|--------------------------|
| poppler-cpp | PDF 解析 | `vcpkg install poppler` |
| libzip | ZIP 容器解析 (Office/EPUB) | `vcpkg install libzip` |
| tesseract + leptonica | OCR 图片文字识别 | `vcpkg install tesseract leptonica` |

## 3. 快速入门

### 基本使用流程

1. **启动程序**：运行 AnyTXT Searcher，主窗口包含搜索栏、结果列表、预览区
2. **输入关键词**：在顶部搜索框输入要查找的内容
3. **执行搜索**：按 **回车** 或点击 **搜索按钮**，即时显示结果
4. **浏览结果**：点击结果条目可在右侧预览文件内容
5. **跳转到段落**：下方"命中段落"列表显示匹配位置，点击定位

### 搜索范围切换

通过下拉框切换搜索范围：

- **全文**：搜索文档全部内容
- **文件名**：仅搜索文件名
- **标题**：搜索文档标题/主题

### 筛选条件

在搜索时可使用筛选条件缩小范围：

| 筛选条件 | 选项 |
|----------|------|
| **文件类型** | PDF、DOCX、TXT、图片、代码、压缩包 |
| **修改时间** | 今天、一周内、一月内、一年内 |
| **文件大小** | 小于1MB、1-100MB、大于100MB |

## 4. 搜索技巧

### 基础搜索

直接输入关键词即可搜索。系统会自动对中文进行分词处理。

### 逻辑运算符

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `&` | AND（与） | `报告 & 2024` — 同时包含"报告"和"2024" |
| `|` | OR（或） | `合同 | 协议` — 包含任一词汇 |
| `-` | NOT（排除） | `方案 -草案` — 包含"方案"但不含"草案" |

### 组合查询

可组合使用多个运算符：
```
项目 & 报告 -年审
```
搜索包含"项目"和"报告"但不含"年审"的文档。

### 短语搜索

使用双引号包裹短语进行精确匹配（需 Xapian 支持）：
```
"机器学习"
```

### 搜索技巧

- 使用 **Ctrl+F** 快速聚焦到搜索框
- 搜索结果按相关性排序，匹配次数越多排序越靠前
- 右侧预览区支持文字高亮，自动标记匹配位置
- 可以使用更具体的词汇缩小搜索范围

## 5. 支持的文件格式

### 全部格式列表

| 格式 | 扩展名 | 解析引擎 | 说明 |
|------|--------|----------|------|
| **纯文本** | `.txt .text .md .markdown .csv .tsv .log .ini .cfg .conf .xml .json .yaml .yml .toml .properties .env` | 内建 | 自动检测各种编码（UTF-8/16, Latin-1） |
| **代码文件** | `.sh .bash .zsh .py .js .ts .jsx .tsx .c .cpp .h .hpp .java .kt .scala .rb .pl .php .rs .go .css .scss .less .sql .r .m .swift .bat .ps1 .lua .html .htm .xhtml .cmake .makefile .dockerfile .gitignore` | 内建 | 覆盖主流编程语言和脚本 |
| **PDF** | `.pdf` | Poppler | 需要 poppler-cpp 库 |
| **Word** | `.docx .docm` | libzip + XML | 读取 word/document.xml |
| **Excel** | `.xlsx .xlsm` | libzip + XML | 读取共享字符串表和工作表 |
| **PowerPoint** | `.pptx .pptm` | libzip + XML | 读取幻灯片文本 |
| **EPUB 电子书** | `.epub` | libzip + XML | 解析 OPF 元数据和 spine |
| **邮件** | `.eml` | 内建 | 解析 MIME 头部和正文 |
| **RTF 富文本** | `.rtf` | 内建 | 状态机去除 RTF 控制字 |
| **老版 Word** | `.doc` | 内建 OLE2 | 解析 OLE2 复合文档 |
| **WPS 文字** | `.wps` | libzip + XML | WPS Office 文字文档 |
| **WPS 表格** | `.et` | libzip + XML | WPS Office 表格文档 |
| **WPS 演示** | `.dps` | libzip + XML | WPS Office 演示文档 |

### 格式支持说明

- **PDF**、**Office 系列** 及其衍生格式需要安装相应的依赖库
- **纯文本**和**代码文件**始终可用，无需额外依赖
- **.doc** 为 Word 97-2003 格式，采用 OLE2 复合文档解析
- **WPS 系列**使用类似 OOXML 的 ZIP+XML 结构

## 6. 索引管理

### 初次使用

首次启动程序时，需要创建索引数据库。索引会扫描指定目录中的文档，建立全文搜索索引。

### 智能索引设置

**工具 → 智能索引设置**：

- 配置自动监控的文件夹
- 被监控文件夹中的新文件会自动编入索引
- 支持排除特定目录或文件类型

### 重建索引

**工具 → 重建索引**：

- 重新扫描所有文档，构建全新索引
- 适用于索引损坏或需要完全重新索引的场景
- 重建过程可能需要较长时间，请耐心等待

### 优化索引

**工具 → 优化索引**：

- 压缩优化索引数据库
- 提升搜索性能
- 建议每月执行一次

### 文件监控

- 监控文件夹中的文件新增、修改、删除操作
- 变更自动同步到索引库
- 可在设置中调整监控间隔

### 索引状态

- 状态栏显示当前索引文档数量和最后索引时间
- 可通过侧边栏文件树浏览已索引的文件
- 索引数据库存储在程序数据目录

## 7. 导入导出

### 导入文档

**文件 → 导入文档**：

- 选择文件或文件夹批量导入
- 支持拖拽文件到程序窗口
- 自动识别格式并提取文本
- 导入进度显示在状态栏

### 导出搜索结果

**文件 → 导出结果**：

- 将当前搜索结果导出为文件
- 支持导出格式：CSV、TXT
- CSV 格式包含：文件名、路径、摘要、修改时间、相关性评分
- TXT 格式为纯文本列表

## 10. 常见问题 (FAQ)

### Q: 搜索不到结果怎么办？

- 确认索引已创建且包含目标目录
- 检查文件格式是否受支持
- 尝试使用更简单的关键词
- 确认文件未被排除在监控之外
- 尝试重建索引

### Q: 支持哪些文件格式？

详见"格式支持"部分。支持 TXT、PDF、DOCX、XLSX、PPTX、EPUB、EML、RTF、DOC 等格式，以及 WPS Office 系列格式（WPS/ET/DPS），还有众多纯文本格式和代码文件。

### Q: 如何安装 PDF/Office 解析支持？

某些格式需要系统安装相应库：

- **PDF**：需要 poppler-cpp 库
- **Office 系列**：需要 libzip 库
- 可以通过包管理器安装，或从源码编译时启用
- 安装后重新编译程序即可启用相应解析器

### Q: 索引文件存储在什么地方？

索引数据库存储在程序数据目录下。具体位置取决于操作系统：

- **Windows**：`%APPDATA%/AnyTXT-Searcher/`
- **Linux**：`~/.local/share/AnyTXT-Searcher/`
- **macOS**：`~/Library/Application Support/AnyTXT-Searcher/`

### Q: 如何提高搜索速度？

- 定期执行"优化索引"精简索引库
- 不搜索不必要的目录（可在监控设置中排除）
- 设置合理的索引范围
- 使用更精确的关键词减少不相关结果

### Q: 索引更新是自动的吗？

是的。被监控的文件夹中的文件新增、修改、删除会自动同步到索引库。也可以通过"文件 → 导入文档"手动添加文件。

### Q: 支持中文分词吗？

是的。AnyTXT Searcher 内置中文分词支持，可以准确搜索中文内容。

### Q: 搜索结果如何排序？

默认按 **相关性** 排序，匹配次数越多排序越靠前。也可以切换为按日期、大小、名称排序。

### Q: 什么是"命中段落"？

"命中段落"是搜索关键词在文档中出现的具体位置列表。点击段落可以快速定位到文档中对应的内容区域。

### Q: 如何排除某些文件或目录？

在智能索引设置中，可以添加排除规则，指定不索引的文件类型、目录或文件名模式。

### Q: 支持网络驱动器上的文件吗？

支持映射的本地网络驱动器。对于需要身份验证的远程路径，请确保程序有足够的文件系统访问权限。

## 11. 故障排除

### 程序无法启动

- 确认系统满足最低要求（Windows 7+ / Linux / macOS）
- 检查所需的运行时库是否安装（Qt DLL、Xapian 等）
- 尝试以管理员权限运行
- 检查日志文件了解具体错误信息

### 搜索无结果或结果不完整

- 确认索引数据库中包含目标文件
- 在侧边栏文件树中查看已索引的文件列表
- 尝试重建索引
- 检查文件格式是否受支持
- 对于新添加的文件，确认已完成索引

### 索引过程慢

- 首次索引大量文件时属于正常现象
- 排除不需要索引的目录
- 避免索引包含大量二进制文件的大目录
- 确保系统有足够的内存和 CPU 资源

### PDF 文件无法解析

- 确认程序已启用 poppler 支持
- 检查 poppler-cpp 库是否正确安装
- 部分加密或受保护的 PDF 可能无法解析
- 扫描版 PDF 需要 OCR 支持（需安装 Tesseract）

### 中文乱码

- 文本文件：程序会自动检测编码，大部分情况可正确处理
- 如果遇到乱码，请确认原文件编码为标准格式
- PDF 等二进制格式的编码由 Poppler 处理

### 索引损坏

- 如果搜索行为异常，尝试重建索引
- 重建索引前建议备份索引目录
- 避免在索引过程中强制关闭程序

### 性能问题

- 大型索引可能导致搜索变慢，建议定期优化
- 预览大量大文件时可能占用较多内存
- 如有持续性能问题，请检查系统资源使用情况

### 获取帮助

如果以上方法无法解决问题：

- 查看日志文件获取详细错误信息
- 联系技术支持或访问项目主页
- 提供日志和操作步骤以便排查
